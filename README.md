# BlockFire

BlockFire is a work-in-progress multiplayer FPS with bot matches, aerial deployment, and loot-based gameplay. The goal is to build toward a more polished, grounded shooter, starting with the basics.

## Current Features

- Multiplayer hosting and Play VS Bots.
- C130 flyover and parachute deployment.
- Weapons, shooting, and reloading.
- Basic inventory and item pickups.
- Loot chests and items including food, armor plates, NVG, and HVG.
- Cities, forests, terrain, buildings, and vehicles.
- Player models, skins, cosmetics, and movement animations.
- A web version with performance improvements.

Features are still being refined, and visual quality varies across the game.

## In Development

### Inventory HUD
- Compact weapon slots with names and icons.
- Equipped-weapon highlighting.
- Clear loaded and reserve ammo displays.
- Responsive positioning to prevent the inventory drifting off-screen.

### Weapons and First-Person View
- Improved first-person hands and animations.
- Reworked weapon models and reload animations.
- Heavier gunshot feedback through recoil and audio effects.

### World and Visuals
- Higher-quality community-created models from sources such as Sketchfab, subject to licensing.
- A more muted, grounded color palette.
- Denser cities and forests.
- Streams, sewage infrastructure, and environmental details.
- More natural terrain and elevation changes.
- Correct building placement on uneven ground.
- Improved chest and loot-item models.

## Development Status

Planned features describe the current direction, not guaranteed release commitments.
